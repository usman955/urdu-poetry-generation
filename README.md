# Urdu Poetry Generation Using N-gram Language Models

## Overview

This project generates Urdu poetry using statistical language models trained on poetry by Faiz Ahmed Faiz, Mirza Ghalib, and Allama Iqbal.

## Models Implemented

- Unigram Language Model
- Forward Bigram Language Model
- Backward Bigram Language Model
- Bidirectional Bigram Language Model
- Trigram Language Model

## Technologies Used

- Python
- Google Colab
- spaCy
- Collections (`Counter`, `defaultdict`)
- Random sampling

## Features

- Urdu text tokenization and preprocessing
- Training statistical n-gram models
- Randomized poetry generation
- Generation of 3 stanzas with 4 verses per stanza
- Verse-length validation

## How to Run

1. Open the notebook in Google Colab.
2. Upload the required poetry corpus files when prompted.
3. Run the notebook cells in order.
4. View the generated poetry and compare the models.

## Limitations

These are statistical language models. They learn word-frequency and word-transition patterns but do not guarantee grammatical accuracy, semantic coherence, or poetic quality.
